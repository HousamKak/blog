My brother opened a coding academy for kids and asked me for a logo. That was the whole brief.

I explored concepts on my prompt canvas and we picked one, then hit the wall every non-designer hits: you cannot edit a generated image in pieces. I wanted to recolour one shape, resize cleanly for a favicon, repaint a corner without losing the rest. So with Claude Code I rebuilt the concept as composable SVG blocks on an isometric grid, instanced through SVG `<use>` tags, with a small brand system on top: a palette, base units and a diamond core. New marks, like the K, fall out of the block grammar instead of being redrawn.

The academy got its logo. I got a question I could not let go of: if moving blocks around in code is this easy for a logo, why not for anything? That question became [BlockForge](/projects/blockforge/).

**Stack:** SVG, JavaScript, Claude Code.
