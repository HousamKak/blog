When I read an unfamiliar codebase I want to mark it up the way I would mark up a paper: highlight a block, write a note next to it, come back tomorrow and find it still there. VS Code does not do that, and the extensions I tried lost their marks the moment the file changed.

Highlightability is a VS Code extension for highlighting code and attaching comments that persist across sessions. The interesting part is anchoring. Highlights are Git-aware, so when lines move because someone edited the file above them, the highlight follows the code instead of staying stuck on the old line numbers.

**Stack:** TypeScript, VS Code API.
