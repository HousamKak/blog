This site. I wanted a blog that reads like a newspaper someone actually typeset, not another white page with a sans-serif headline, so I built it from scratch in Astro, Tailwind and MDX.

Everything is a file: posts, papers, notes, renders (including interactive applets), front pages and the projects on this docket each live in their own collection. Every page renders to static HTML at build time, and interactivity is opt-in through React islands, so a post with a GPU fractal viewer loads the fractal code and a plain essay loads nothing.

Each post can pick its own theme. The default is a quiet broadsheet; the Chaos Edition front page is a collage of tape, pushpins, horoscopes, classifieds and obituaries for dead browsers.

**Stack:** Astro, Tailwind CSS, MDX, KaTeX (at build time), Shiki, Three.js and react-three-fiber for 3D renders, hosted on GitHub Pages.
